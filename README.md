## Запуск

1. Установите Node.js 20 или новее.
2. Откройте папку репозитория в VS Code.
3. В терминале запустите `npm start` или `npm.cmd start`(зависимости устанавливать не требуется).
4. Откройте `http://localhost:3047` в браузере.
5. Исследуйте запросы во вкладке **DevTools → Network → Fetch/XHR**.

Не открывайте `index.html` через `file://` и не запускайте Live Server: HTTP API обслуживает `server.js`.

## API

- `GET /api/tasks` → `{items, total}`.
- `POST /api/tasks` → `{title, category, priority}`, ответ HTTP 201.
- `PATCH /api/tasks/:id` → `{done: true/false}`, ответ HTTP 200.
- `DELETE /api/tasks/:id` → ответ HTTP 204 без тела.
- Ошибки валидации — 422, отсутствующий ID — 404.

## Проверка

Загрузка, создание, переключение выполнения и удаление работают через сервер; фильтры и счётчики корректны; нет обновления всей страницы; отображаются ошибки.
